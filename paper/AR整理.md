一、联合分布建模的动机与方法

联合分布（Joint Distribution）

- 使用独立分布来建模联合分布是很方便的：  
  
  p(x_1, x_2) = p(x_1),p(x_2)
    
  此时条件分布等于边缘分布：  
  
  p(x_2 mid x_1) = p(x_2)

联合分布（续）

- 然而，现实世界的问题总是涉及相互依赖的变量：  
  
  p(x_1, x_2)
    
  此时条件分布不等于边缘分布：  
  
  p(x_2 mid x_1) neq p(x_2)

如何建模联合分布？（How to Model Joint Distributions?）

方案 1：通过独立隐变量建模（例如 VAE）  
- 映射方式：独立隐变量 ⇒ 依赖的观测变量；  
- 对高维数据（例如 32×32×3 像素的图像）来说，这是一个很强的假设；  
- 通常使用低维隐变量；  
- 是一个良好的构建模块，但往往不够充分（难以捕捉复杂依赖）。

如何建模联合分布？（续）

方案 1：通过独立隐变量建模  
方案 2：通过条件分布建模

条件分布建模（Conditional Distribution Modeling）

- 链式法则（Chain Rule）：  
  任何联合分布都可以写成条件分布的乘积。  
  例如：  
  
  p(A, B, C) = p(A),p(B mid A),p(C mid A, B)

案例研究：条件分布建模（Case Study: Conditional Distribution Modeling）

案例 1：对输入表示空间 x 进行划分  
- 示例：在文本词元（tokens）或像素上应用自回归模型。

案例研究：条件分布建模（续）

案例 2：对隐表示空间 z 进行划分  
- 示例：在 VQ-VAE 生成的离散隐 token 上应用自回归模型。

案例研究：条件分布建模（续）

案例 3：逐步变换数据分布（Progressively transforming data distributions）  
- 示例：扩散模型（Diffusion Models）

注：扩散模型也依赖于条件分布建模的思想——通过一系列小步的条件转换（如 p(x_t mid x_{t+1})），从简单噪声逐步重构复杂数据分布。

二、条件分布建模的核心思想

条件分布建模

与深度学习同源的精神：“分而治之”（Divide-and-Conquer）  
- 导数的链式法则（用于反向传播 / backprop）  
- 概率的链式法则（用于联合分布分解）

使用神经网络对每个条件分布进行建模

p(A, B, C) = p_theta(A), p_phi(B mid A), p_psi(C mid A, B)

注意：  
- 对联合分布 p(A, B, C) 建模 vs. 对条件分布 p(C mid A, B) 建模？  
  - p(A, B, C) 涉及 3 个变量；  
  - p(C mid A, B) 只涉及 1 个变量（输出），但有 2 个条件（作为网络输入）。  
- 权重共享问题？  
  - 从概念上讲，每个条件分布都有自己的参数（权重）；  
  - 如果共享权重，则引入了归纳偏置（inductive biases，后文会讨论）。

依赖图（Dependency Graphs）

- 将联合分布分解 ⇒ 会诱导出一个依赖图；  
- 依赖图反映了先验知识。

例如：  

p(A, B, C) = p(A), p(B mid A), p(C mid A, B)

依赖图（续）

- 某些依赖图可能会导致更简单的分布……

例如，以下两种分解都是有效的：  

p(A, B, C) = p(A), p(B mid A), p(C mid A, B)
  

p(A, B, C) = p(C), p(B mid C), p(A mid B, C)

依赖图（续）

- 某些依赖图可能会导致更简单的分布……  
  （例如，若 C 是“原因”，则以 C 为根的分解可能更自然）

条件分布建模 —— 小结

- 联合分布 ⇒ 条件分布的乘积；  
- 利用概率的链式法则（chain rule）实现“分而治之”（divide-and-conquer）；  
- 分解顺序和划分方式可以任意（任何顺序、任何划分）；  
- 依赖图体现了建模时引入的先验知识。  

注：以上思想并不仅限于自回归（Autoregressive）模型。

二、什么是自回归（Autoregressive）？

Auto + Regression

- Auto（“自”）：  
  指的是在预测时使用模型“自身”的输出作为下一步的输入。

- Regression（回归）：  
  指的是估计变量之间的关系。

注意：  
- “自回归”描述的是一种推理阶段（inference-time）的行为；  
- 训练阶段（training-time）不一定采用自回归方式（例如可以使用“教师强制/teacher forcing”）。

- 不一定是序列或时间数据；  
  - 例如：一个向量的所有维度；  
  - 例如：2D、3D 或高维数组（如图像、体素等）。

从概念上讲……

  - 顺序：例如，逆序也是合法的；

自回归模型（续）

一般来说，自回归是一种通过条件分布的乘积来建模联合分布的方法：

从概念上讲……  
- 每个条件分布 p(x_i mid x_{<i}) 可以采用任意形式建模；  
  - 例如：查找表（look-up tables）、决策树、神经网络，或它们的混合；  
  - 变量可以是离散的，也可以是连续的。

自回归模型（续）

一般来说，自回归是一种通过条件分布的乘积来建模联合分布的方法：

这种形式没有做任何近似或妥协：  
- 这种分解总是成立的（仅仅是概率的链式法则）；  
- 但某些分解方式更容易建模——这就是所谓的 “归纳偏置（inductive bias）”。

三、归纳偏置（Inductive Bias）

（回顾）我们希望所选的分解方式能给出更简单的条件分布……

例如：  

p(A, B, C) = p(A),p(B mid A),p(C mid A, B)
  

p(A, B, C) = p(C),p(B mid C),p(A mid B, C)

你的手机键盘就是一个自回归系统：  
之前的输出（已输入的词）能大幅缩小下一个可能输出（候选词）的范围。

在这种场景下，每一个 p 都是一个类别分布（categorical distribution）。

归纳偏置

我们希望分解后的条件分布是更容易建模的……  

例子：“下一个词元预测”（next token prediction）  
- 使用时间顺序（temporal modeling）本身就引入了一种归纳偏置。

归纳偏置

我们希望这些被分解出的条件分布能由“相似”的神经网络来表示……

- 从概念上讲，每个条件分布 p(x_i mid x_{<i}) 是一个不同的映射函数；  
- 但我们用共享的网络架构来建模它们  
  （例如 RNN、CNN、Transformer 等）。

归纳偏置

我们希望这些被分解出的条件分布能由“相似”的神经网络来表示……

- 从概念上讲，每个条件分布是不同的映射；  
- 但我们不仅共享架构，还共享权重 theta：

theta quad theta quad theta

这种权重共享是一种强归纳偏置——它假设不同位置的条件生成过程具有相似的底层规律。

归纳偏置（总结）

（回顾）联合分布的链式分解本身没有近似，完全精确；  
但我们在实际建模时引入的归纳偏置会带来近似，例如：  
- 共享网络架构  
- 共享参数（权重）  
- 特定的变量排序或分解方式  

这些选择限制了模型的表达能力，但通常能提升泛化性和训练效率。

表示一个分布（Representing One Distribution）

- 网络输入：已观测到的上下文（如 x_{<i}）  
- 网络输出：对下一个变量 x_i 的概率分布

该分布可以是：  
- 连续分布（如高斯分布、混合密度等）  
- 离散分布（如类别分布）

注意：  
- 当输出是离散分布时，该网络的行为类似于分类器——这正是“自回归”中“回归（regression）”一词在实践中的常见形式（尽管名字叫 regression，实际常做 classification）；  
- 虽然离散分布在自回归模型中非常流行（如语言模型），但它并非必需——自回归同样可用于连续数据（如 WaveNet 生成音频波形）。

考虑 x_6 的一条梯度路径：  
- 需要穿过所有之前的输出……  
- 穿过所有之前的采样操作（sampling operations）……  
- 穿过所有之前的网络模块（例如每一步都用一个完整的 Transformer）

结果：  
按照推理时的计算图来训练自回归模型是不可行的（计算开销巨大，且采样操作通常不可导）。

训练：教师强制（Training: Teacher Forcing）

教师强制（Teacher Forcing）：  
- 输入不是来自模型之前的输出；  
- 输入直接来自真实数据（ground-truth）。

教师强制（续）

优点：  
- 反向传播路径大大缩短（每个时间步独立计算梯度）；  
- 使用真实输入有助于训练稳定性（避免错误累积）。

教师强制（续）

缺点：  
- 训练与推理不一致（exposure bias）：  
  - 训练时看到的是“正确历史”，  
  - 推理时却只能依赖“自己生成的历史”；  
- 分布偏移（distribution shift）：  
  - 模型在训练中从未见过自己犯错的情况，  
  - 一旦推理时出错，错误可能被放大并导致后续预测崩溃。

带共享计算的自回归（Autoregression with Shared Computation）

我们可以用单个网络来实现整个自回归分解，前提是满足以下条件：

- 每个输出 x_i 不依赖于任何 x_j（其中 j geq i）  
  → 即满足因果性（causality） 或 自回归顺序约束。

在此前提下，该单个网络可以实现：
- 共享架构（shared architecture）  
- 共享参数（shared weights）  
- 共享中间计算（shared computation）

七、不同架构中的自回归实现

简介：用于自回归的循环神经网络（RNN）

- 一个 RNN 单元（one RNN unit）  
  → 通过时间展开（unfold in “time”） 来处理序列。

- “Go deep”  
  → 可以堆叠多层 RNN 实现深度结构（deep RNN），增强表达能力。

- 将目标（target）向后平移一步（shift target by one step）  
  → 在训练时，输入序列为 [x_1, x_2, ..., x_{T-1}]，目标序列为 [x_2, x_3, ..., x_T]；  
  → 这样 RNN 在时刻 t 的输出就用于预测下一个 token x_{t+1}，符合自回归建模目标：  
  
  p(x_{t+1} mid x_{leq t})

简介：用于自回归的卷积神经网络（CNN）

- 一维卷积（1-D convolution）  
  → 将输入序列（如文本或音频）视为一维信号进行处理。

- 使用填充（with padding）  
  → 保持输出序列长度与输入一致，便于对齐每个位置的预测。

- 因果卷积（Causal Convolution）  
  → 卷积核仅依赖当前及过去的位置，不依赖“未来”信息；  
  → 通过不对称填充或裁剪确保在位置 t 的输出只基于 x_{leq t}，满足自回归的因果性要求。

- “Go deep”（加深网络）  
  → 堆叠多层因果卷积以扩大感受野（receptive field），从而捕获更长距离的依赖关系；  
  → 可结合空洞卷积（dilated convolution）（如 WaveNet）高效扩展上下文范围。

- 将目标（target）向后平移一步（shift target by one step）  
  → 输入为 [x_1, x_2, ..., x_{T-1}]，目标为 [x_2, x_3, ..., x_T]；  
  → 网络在位置 t 的输出用于预测 x_{t+1}，即建模 p(x_{t+1} mid x_{leq t})。

简介：用于自回归的注意力机制（Transformer）

- 全注意力（Full Attention）  
  → 每个位置可以“看到”序列中的所有其他位置（包括未来）；  
  → 不适用于自回归建模，因为会泄露未来信息。

简介：用于自回归的注意力机制（续）

- 因果注意力（Causal Attention）  
  → 通过注意力掩码（attention mask） 禁止每个位置关注其未来的位置；  
  → 在位置 t，只能 attend 到 x_1, x_2, dots, x_t，确保满足自回归的因果性：  
  
  p(x_{t+1} mid x_{leq t})
  

- “Go deep”（加深网络）  
  → 堆叠多层带因果掩码的 Transformer 块，逐步提取更丰富的上下文表示；  
  → 每一层都保持因果约束，整体仍为合法的自回归模型。

- 将目标（target）向后平移一步（shift target by one step）  
  → 输入序列为 [x_1, x_2, ..., x_{T-1}]，目标序列为 [x_2, x_3, ..., x_T]；  
  → 模型在位置 t 的输出用于预测下一个 token x_{t+1}。

八、最终总结

自回归模型总结（Summary: Autoregressive Models）

核心要点（Takeaways）：

- 联合分布分解为条件分布的乘积  
  
  p(x_1, x_2, dots, x_T) = prod_{t=1}^T p(x_t mid x_{<t})
    
  → 这是概率链式法则的直接应用，精确无近似。

- 归纳偏置（Inductive Bias）体现在：  
  - 共享的网络架构（shared architecture）  
  - 共享的参数权重（shared weights）  
  - 人为指定的生成顺序（induced order，如从左到右、光栅扫描等）

- 推理阶段（Inference）：  
  → 自回归方式生成：每一步将前序生成的输出作为当前输入，逐步采样。

- 训练阶段（Training）：  
  → 通常采用 教师强制（Teacher Forcing）：使用真实历史（ground-truth）作为输入，而非模型自身预测。

- 实现架构灵活：  
  → 自回归建模不绑定特定神经网络结构，可由以下任一实现：  
  - RNN（通过隐藏状态传递历史）  
  - CNN（通过因果卷积，如 PixelCNN / WaveNet）  
  - Transformer（通过因果注意力掩码，如 GPT）

✅ 关键思想：自回归是一种建模范式（如何分解和生成联合分布），而非某种特定模型。不同架构只是实现这一范式的不同工具。
