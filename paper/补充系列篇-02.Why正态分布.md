# 补充系列篇-02.Why正态分布: 为什么生成模型常使用正态分布

在生成模型中，我们经常看到使用标准正态分布 $\mathcal{N}(0, I)$ 作为先验分布。这并非偶然，而是基于正态分布独特的数学性质。本文重点介绍正态分布的两个核心性质:**加法法则**和**乘法法则（共轭性）**。
如果你对推导不感兴趣，请直接看最后的总结部分。

## 1. 加法法则:正态分布的和仍然是正态分布

### 1.1 定理陈述

**定理**:设 $X_1 \sim \mathcal{N}(\mu_1, \sigma_1^2)$ 和 $X_2 \sim \mathcal{N}(\mu_2, \sigma_2^2)$ 是两个独立的一维正态分布随机变量，则它们的和 $Y = X_1 + X_2$ 也服从正态分布:

$$Y = X_1 + X_2 \sim \mathcal{N}(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$$

### 1.2 证明方法1:特征函数法

正态分布 $\mathcal{N}(\mu, \sigma^2)$ 的特征函数为:
$$\phi_X(t) = \mathbb{E}[e^{itX}] = \exp\left(it\mu - \frac{1}{2}\sigma^2 t^2\right)$$

对于 $Y = X_1 + X_2$，由于 $X_1$ 和 $X_2$ 独立:
$$\begin{aligned}
\phi_Y(t) &= \mathbb{E}[e^{itY}] = \mathbb{E}[e^{it(X_1 + X_2)}] \\
&= \mathbb{E}[e^{itX_1}] \cdot \mathbb{E}[e^{itX_2}] \quad \text{（独立性）} \\
&= \phi_{X_1}(t) \cdot \phi_{X_2}(t) \\
&= \exp\left(it\mu_1 - \frac{1}{2}\sigma_1^2 t^2\right) \cdot \exp\left(it\mu_2 - \frac{1}{2}\sigma_2^2 t^2\right) \\
&= \exp\left(it(\mu_1 + \mu_2) - \frac{1}{2}(\sigma_1^2 + \sigma_2^2) t^2\right)
\end{aligned}$$

这正是 $\mathcal{N}(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$ 的特征函数。由于特征函数唯一确定分布，因此:
$$Y \sim \mathcal{N}(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$$

### 1.3 证明方法2:卷积法

两个独立随机变量的和的概率密度函数是它们的卷积:
$$p_Y(y) = \int_{-\infty}^{\infty} p_{X_1}(x) p_{X_2}(y-x) dx$$

将正态分布的概率密度函数代入:
$$p_{X_1}(x) = \frac{1}{\sqrt{2\pi\sigma_1^2}} \exp\left(-\frac{(x-\mu_1)^2}{2\sigma_1^2}\right)$$
$$p_{X_2}(y-x) = \frac{1}{\sqrt{2\pi\sigma_2^2}} \exp\left(-\frac{(y-x-\mu_2)^2}{2\sigma_2^2}\right)$$

因此:
$$\begin{aligned}
p_Y(y) &= \int_{-\infty}^{\infty} \frac{1}{\sqrt{2\pi\sigma_1^2}} \exp\left(-\frac{(x-\mu_1)^2}{2\sigma_1^2}\right) \cdot \frac{1}{\sqrt{2\pi\sigma_2^2}} \exp\left(-\frac{(y-x-\mu_2)^2}{2\sigma_2^2}\right) dx \\
&= \frac{1}{2\pi\sigma_1\sigma_2} \int_{-\infty}^{\infty} \exp\left(-\frac{(x-\mu_1)^2}{2\sigma_1^2} - \frac{(y-x-\mu_2)^2}{2\sigma_2^2}\right) dx
\end{aligned}$$

**步骤1:整理指数部分**

令:
$$A = \frac{(x-\mu_1)^2}{2\sigma_1^2} + \frac{(y-x-\mu_2)^2}{2\sigma_2^2}$$

展开第一个平方项:
$$(x-\mu_1)^2 = x^2 - 2\mu_1 x + \mu_1^2$$

展开第二个平方项:
$$(y-x-\mu_2)^2 = (y-\mu_2-x)^2 = (y-\mu_2)^2 - 2(y-\mu_2)x + x^2$$

因此:
$$\begin{aligned}
A &= \frac{x^2 - 2\mu_1 x + \mu_1^2}{2\sigma_1^2} + \frac{(y-\mu_2)^2 - 2(y-\mu_2)x + x^2}{2\sigma_2^2} \\
&= \frac{\sigma_2^2(x^2 - 2\mu_1 x + \mu_1^2) + \sigma_1^2((y-\mu_2)^2 - 2(y-\mu_2)x + x^2)}{2\sigma_1^2\sigma_2^2} \\
&= \frac{\sigma_2^2x^2 - 2\sigma_2^2\mu_1 x + \sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2 - 2\sigma_1^2(y-\mu_2)x + \sigma_1^2x^2}{2\sigma_1^2\sigma_2^2} \\
&= \frac{(\sigma_1^2 + \sigma_2^2)x^2 - 2[\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)]x + \sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2}{2\sigma_1^2\sigma_2^2}
\end{aligned}$$

**步骤2:对 $x$ 进行配方法**

将 $A$ 写成关于 $x$ 的二次型:
$$A = \frac{(\sigma_1^2 + \sigma_2^2)x^2 - 2[\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)]x + \sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2}{2\sigma_1^2\sigma_2^2}$$

提取 $x^2$ 的系数:
$$\begin{aligned}
A &= \frac{(\sigma_1^2 + \sigma_2^2)}{2\sigma_1^2\sigma_2^2} \left[x^2 - 2 \cdot \frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}x + \frac{\sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2}{\sigma_1^2 + \sigma_2^2}\right]
\end{aligned}$$

为了配成完全平方，我们需要:
$$\left(x - \frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}\right)^2 = x^2 - 2 \cdot \frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}x + \left(\frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}\right)^2$$

因此:
$$\begin{aligned}
A &= \frac{(\sigma_1^2 + \sigma_2^2)}{2\sigma_1^2\sigma_2^2} \left[\left(x - \frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}\right)^2 - \left(\frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}\right)^2 + \frac{\sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2}{\sigma_1^2 + \sigma_2^2}\right]
\end{aligned}$$

令:
$$\mu_Y = \frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}, \quad \sigma_Y^2 = \frac{\sigma_1^2\sigma_2^2}{\sigma_1^2 + \sigma_2^2}$$

则:
$$A = \frac{(x - \mu_Y)^2}{2\sigma_Y^2} + \text{常数项}$$

其中常数项为:
$$\text{常数项} = \frac{(\sigma_1^2 + \sigma_2^2)}{2\sigma_1^2\sigma_2^2} \left[-\mu_Y^2 + \frac{\sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2}{\sigma_1^2 + \sigma_2^2}\right]$$

**步骤3:计算常数项**

首先展开 $\mu_Y^2$:
$$\begin{aligned}
\mu_Y^2 &= \left(\frac{\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)}{\sigma_1^2 + \sigma_2^2}\right)^2 \\
&= \frac{[\sigma_2^2\mu_1 + \sigma_1^2(y-\mu_2)]^2}{(\sigma_1^2 + \sigma_2^2)^2} \\
&= \frac{\sigma_2^4\mu_1^2 + 2\sigma_1^2\sigma_2^2\mu_1(y-\mu_2) + \sigma_1^4(y-\mu_2)^2}{(\sigma_1^2 + \sigma_2^2)^2}
\end{aligned}$$

计算常数项:
$$\begin{aligned}
\text{常数项} &= \frac{(\sigma_1^2 + \sigma_2^2)}{2\sigma_1^2\sigma_2^2} \left[-\mu_Y^2 + \frac{\sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2}{\sigma_1^2 + \sigma_2^2}\right] \\
&= \frac{1}{2\sigma_1^2\sigma_2^2} \left[-\mu_Y^2(\sigma_1^2 + \sigma_2^2) + \sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2\right] \\
&= \frac{1}{2\sigma_1^2\sigma_2^2} \left[-\frac{\sigma_2^4\mu_1^2 + 2\sigma_1^2\sigma_2^2\mu_1(y-\mu_2) + \sigma_1^4(y-\mu_2)^2}{\sigma_1^2 + \sigma_2^2} + \sigma_2^2\mu_1^2 + \sigma_1^2(y-\mu_2)^2\right]
\end{aligned}$$

通分并整理:
$$\begin{aligned}
\text{常数项} &= \frac{1}{2\sigma_1^2\sigma_2^2(\sigma_1^2 + \sigma_2^2)} \left[-\sigma_2^4\mu_1^2 - 2\sigma_1^2\sigma_2^2\mu_1(y-\mu_2) - \sigma_1^4(y-\mu_2)^2 + \sigma_2^2\mu_1^2(\sigma_1^2 + \sigma_2^2) + \sigma_1^2(y-\mu_2)^2(\sigma_1^2 + \sigma_2^2)\right] \\
&= \frac{1}{2\sigma_1^2\sigma_2^2(\sigma_1^2 + \sigma_2^2)} \left[-\sigma_2^4\mu_1^2 - 2\sigma_1^2\sigma_2^2\mu_1(y-\mu_2) - \sigma_1^4(y-\mu_2)^2 + \sigma_1^2\sigma_2^2\mu_1^2 + \sigma_2^4\mu_1^2 + \sigma_1^4(y-\mu_2)^2 + \sigma_1^2\sigma_2^2(y-\mu_2)^2\right] \\
&= \frac{1}{2\sigma_1^2\sigma_2^2(\sigma_1^2 + \sigma_2^2)} \left[\sigma_1^2\sigma_2^2\mu_1^2 - 2\sigma_1^2\sigma_2^2\mu_1(y-\mu_2) + \sigma_1^2\sigma_2^2(y-\mu_2)^2\right] \\
&= \frac{1}{2(\sigma_1^2 + \sigma_2^2)} \left[\mu_1^2 - 2\mu_1(y-\mu_2) + (y-\mu_2)^2\right] \\
&= \frac{1}{2(\sigma_1^2 + \sigma_2^2)} [\mu_1 - (y-\mu_2)]^2 \\
&= \frac{1}{2(\sigma_1^2 + \sigma_2^2)} (\mu_1 + \mu_2 - y)^2 \\
&= \frac{(y - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)}
\end{aligned}$$

因此:
$$A = \frac{(x - \mu_Y)^2}{2\sigma_Y^2} + \frac{(y - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)}$$

**步骤4:完成积分**

将 $A$ 代入积分式:
$$\begin{aligned}
p_Y(y) &= \frac{1}{2\pi\sigma_1\sigma_2} \int_{-\infty}^{\infty} \exp(-A) dx \\
&= \frac{1}{2\pi\sigma_1\sigma_2} \exp\left(-\frac{(y - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)}\right) \int_{-\infty}^{\infty} \exp\left(-\frac{(x - \mu_Y)^2}{2\sigma_Y^2}\right) dx
\end{aligned}$$

利用高斯积分公式:
$$\int_{-\infty}^{\infty} \exp\left(-\frac{(x - \mu_Y)^2}{2\sigma_Y^2}\right) dx = \sqrt{2\pi\sigma_Y^2}$$

因此:
$$\begin{aligned}
p_Y(y) &= \frac{1}{2\pi\sigma_1\sigma_2} \exp\left(-\frac{(y - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)}\right) \cdot \sqrt{2\pi\sigma_Y^2} \\
&= \frac{1}{2\pi\sigma_1\sigma_2} \exp\left(-\frac{(y - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)}\right) \cdot \sqrt{2\pi} \cdot \frac{\sigma_1\sigma_2}{\sqrt{\sigma_1^2 + \sigma_2^2}} \\
&= \frac{1}{\sqrt{2\pi(\sigma_1^2 + \sigma_2^2)}} \exp\left(-\frac{(y - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)}\right)
\end{aligned}$$

这正是 $\mathcal{N}(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$ 的概率密度函数，因此:
$$Y \sim \mathcal{N}(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$$

### 1.4 多维情况的推广

对于多维情况，设 $\mathbf{X}_1 \sim \mathcal{N}(\boldsymbol{\mu}_1, \Sigma_1)$，$\mathbf{X}_2 \sim \mathcal{N}(\boldsymbol{\mu}_2, \Sigma_2)$，且 $\mathbf{X}_1$ 和 $\mathbf{X}_2$ 独立。

多维正态分布的特征函数为:
$$\phi_{\mathbf{X}}(\mathbf{t}) = \exp\left(i\mathbf{t}^T\boldsymbol{\mu} - \frac{1}{2}\mathbf{t}^T\Sigma\mathbf{t}\right)$$

对于 $\mathbf{Y} = \mathbf{X}_1 + \mathbf{X}_2$:
$$\begin{aligned}
\phi_{\mathbf{Y}}(\mathbf{t}) &= \mathbb{E}[e^{i\mathbf{t}^T\mathbf{Y}}] = \mathbb{E}[e^{i\mathbf{t}^T(\mathbf{X}_1 + \mathbf{X}_2)}] \\
&= \mathbb{E}[e^{i\mathbf{t}^T\mathbf{X}_1}] \cdot \mathbb{E}[e^{i\mathbf{t}^T\mathbf{X}_2}] \quad \text{（独立性）} \\
&= \exp\left(i\mathbf{t}^T\boldsymbol{\mu}_1 - \frac{1}{2}\mathbf{t}^T\Sigma_1\mathbf{t}\right) \cdot \exp\left(i\mathbf{t}^T\boldsymbol{\mu}_2 - \frac{1}{2}\mathbf{t}^T\Sigma_2\mathbf{t}\right) \\
&= \exp\left(i\mathbf{t}^T(\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2) - \frac{1}{2}\mathbf{t}^T(\Sigma_1 + \Sigma_2)\mathbf{t}\right)
\end{aligned}$$

因此:
$$\mathbf{Y} \sim \mathcal{N}(\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2, \Sigma_1 + \Sigma_2)$$

## 2. 乘法法则:正态分布的共轭性

### 2.1 共轭先验的概念

在贝叶斯推断中，如果先验分布和似然函数属于同一分布族，且后验分布也属于同一分布族，则称该先验为**共轭先验**（Conjugate Prior）。

**正态分布是正态似然的共轭先验**:如果先验 $p(X)$ 和似然 $p(Y|X)$ 都是正态分布，则后验 $p(X|Y)$ 也是正态分布。

### 2.2 一维情况的证明

**设定**:
- 先验:$X \sim \mathcal{N}(\mu_X, \sigma_X^2)$
- 似然:$Y|X \sim \mathcal{N}(X, \sigma_Y^2)$（已知 $\sigma_Y^2$）
- 观测:$Y = y$（单个观测值）

**后验分布**:

根据贝叶斯定理:
$$p(X|Y=y) \propto p(X) \cdot p(Y=y|X)$$

其中 $\propto$ 表示"正比于"，即忽略归一化常数。

**步骤1:写出先验和似然**

先验分布:
$$p(X) = \frac{1}{\sqrt{2\pi\sigma_X^2}} \exp\left(-\frac{(X - \mu_X)^2}{2\sigma_X^2}\right) \propto \exp\left(-\frac{(X - \mu_X)^2}{2\sigma_X^2}\right)$$

似然函数:
$$p(Y=y|X) = \frac{1}{\sqrt{2\pi\sigma_Y^2}} \exp\left(-\frac{(y - X)^2}{2\sigma_Y^2}\right) \propto \exp\left(-\frac{(y - X)^2}{2\sigma_Y^2}\right)$$

**步骤2:写出后验分布（忽略归一化常数）**

$$\begin{aligned}
p(X|Y=y) &\propto p(X) \cdot p(Y=y|X) \\
&\propto \exp\left(-\frac{(X - \mu_X)^2}{2\sigma_X^2}\right) \cdot \exp\left(-\frac{(y - X)^2}{2\sigma_Y^2}\right) \\
&= \exp\left(-\frac{(X - \mu_X)^2}{2\sigma_X^2} - \frac{(y - X)^2}{2\sigma_Y^2}\right)
\end{aligned}$$

**步骤3:展开指数部分**

展开第一项:
$$(X - \mu_X)^2 = X^2 - 2\mu_X X + \mu_X^2$$

展开第二项:
$$(y - X)^2 = y^2 - 2yX + X^2$$

因此:
$$\begin{aligned}
&-\frac{(X - \mu_X)^2}{2\sigma_X^2} - \frac{(y - X)^2}{2\sigma_Y^2} \\
&= -\frac{X^2 - 2\mu_X X + \mu_X^2}{2\sigma_X^2} - \frac{y^2 - 2yX + X^2}{2\sigma_Y^2} \\
&= -\frac{X^2}{2\sigma_X^2} + \frac{\mu_X X}{\sigma_X^2} - \frac{\mu_X^2}{2\sigma_X^2} - \frac{y^2}{2\sigma_Y^2} + \frac{yX}{\sigma_Y^2} - \frac{X^2}{2\sigma_Y^2}
\end{aligned}$$

整理成关于 $X$ 的二次型:
$$\begin{aligned}
&= -\frac{1}{2}\left(\frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}\right)X^2 + \left(\frac{\mu_X}{\sigma_X^2} + \frac{y}{\sigma_Y^2}\right)X + \text{常数项}
\end{aligned}$$

**步骤4:配方法**

为了将上式配成 $-\frac{(X - \mu_{X|Y})^2}{2\sigma_{X|Y}^2}$ 的形式，我们需要:

1. 确定 $\sigma_{X|Y}^2$:
   $$-\frac{1}{2\sigma_{X|Y}^2} = -\frac{1}{2}\left(\frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}\right)$$

   因此:
   $$\frac{1}{\sigma_{X|Y}^2} = \frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}$$

   或者写成:
   $$\sigma_{X|Y}^2 = \frac{\sigma_X^2 \sigma_Y^2}{\sigma_X^2 + \sigma_Y^2}$$

2. 确定 $\mu_{X|Y}$:
   完全平方项为:
   $$-\frac{(X - \mu_{X|Y})^2}{2\sigma_{X|Y}^2} = -\frac{X^2 - 2\mu_{X|Y}X + \mu_{X|Y}^2}{2\sigma_{X|Y}^2} = -\frac{X^2}{2\sigma_{X|Y}^2} + \frac{\mu_{X|Y}X}{\sigma_{X|Y}^2} - \frac{\mu_{X|Y}^2}{2\sigma_{X|Y}^2}$$

   对比系数，$X$ 的一次项系数应该相等:
   $$\frac{\mu_{X|Y}}{\sigma_{X|Y}^2} = \frac{\mu_X}{\sigma_X^2} + \frac{y}{\sigma_Y^2}$$

   因此:
   $$\mu_{X|Y} = \sigma_{X|Y}^2 \left(\frac{\mu_X}{\sigma_X^2} + \frac{y}{\sigma_Y^2}\right)$$

**步骤5:验证配方法**

展开 $-\frac{(X - \mu_{X|Y})^2}{2\sigma_{X|Y}^2}$:
$$\begin{aligned}
-\frac{(X - \mu_{X|Y})^2}{2\sigma_{X|Y}^2} &= -\frac{X^2 - 2\mu_{X|Y}X + \mu_{X|Y}^2}{2\sigma_{X|Y}^2} \\
&= -\frac{1}{2}\left(\frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}\right)X^2 + \frac{\mu_{X|Y}}{\sigma_{X|Y}^2}X - \frac{\mu_{X|Y}^2}{2\sigma_{X|Y}^2} \\
&= -\frac{1}{2}\left(\frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}\right)X^2 + \left(\frac{\mu_X}{\sigma_X^2} + \frac{y}{\sigma_Y^2}\right)X - \frac{\mu_{X|Y}^2}{2\sigma_{X|Y}^2}
\end{aligned}$$

这与步骤3中的结果一致（除了常数项），因此配方法正确。

**步骤6:写出后验分布**

因此，后验分布为:
$$p(X|Y=y) = \mathcal{N}(\mu_{X|Y}, \sigma_{X|Y}^2)$$

其中:
$$\begin{aligned}
\frac{1}{\sigma_{X|Y}^2} &= \frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2} \\
\mu_{X|Y} &= \sigma_{X|Y}^2 \left(\frac{\mu_X}{\sigma_X^2} + \frac{y}{\sigma_Y^2}\right)
\end{aligned}$$

**后验参数的直观解释**:
- $\frac{1}{\sigma_{X|Y}^2} = \frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}$:后验精度 = 先验精度 + 似然精度
- $\mu_{X|Y}$:后验均值是先验均值 $\mu_X$ 和观测值 $y$ 的加权平均，权重与各自的精度成正比

### 2.3 多维情况的证明

**设定**:
- 先验:$\mathbf{X} \sim \mathcal{N}(\boldsymbol{\mu}_X, \Sigma_X)$
- 似然:$\mathbf{Y}|\mathbf{X} \sim \mathcal{N}(\mathbf{X}, \Sigma_Y)$（已知 $\Sigma_Y$）
- 观测:$\mathbf{Y} = \mathbf{y}$（单个观测向量）

**后验分布**:

根据贝叶斯定理:
$$p(\mathbf{X}|\mathbf{Y}=\mathbf{y}) \propto p(\mathbf{X}) \cdot p(\mathbf{Y}=\mathbf{y}|\mathbf{X})$$

先验分布:
$$p(\mathbf{X}) \propto \exp\left(-\frac{1}{2}(\mathbf{X} - \boldsymbol{\mu}_X)^T\Sigma_X^{-1}(\mathbf{X} - \boldsymbol{\mu}_X)\right)$$

似然函数:
$$p(\mathbf{Y}=\mathbf{y}|\mathbf{X}) \propto \exp\left(-\frac{1}{2}(\mathbf{y} - \mathbf{X})^T\Sigma_Y^{-1}(\mathbf{y} - \mathbf{X})\right)$$

**步骤1:展开指数部分**

先验部分:
$$(\mathbf{X} - \boldsymbol{\mu}_X)^T\Sigma_X^{-1}(\mathbf{X} - \boldsymbol{\mu}_X) = \mathbf{X}^T\Sigma_X^{-1}\mathbf{X} - 2\boldsymbol{\mu}_X^T\Sigma_X^{-1}\mathbf{X} + \boldsymbol{\mu}_X^T\Sigma_X^{-1}\boldsymbol{\mu}_X$$

似然部分:
$$(\mathbf{y} - \mathbf{X})^T\Sigma_Y^{-1}(\mathbf{y} - \mathbf{X}) = \mathbf{y}^T\Sigma_Y^{-1}\mathbf{y} - 2\mathbf{y}^T\Sigma_Y^{-1}\mathbf{X} + \mathbf{X}^T\Sigma_Y^{-1}\mathbf{X}$$

**步骤2:整理成二次型**

后验分布的指数部分为:
$$\begin{aligned}
&-\frac{1}{2}(\mathbf{X} - \boldsymbol{\mu}_X)^T\Sigma_X^{-1}(\mathbf{X} - \boldsymbol{\mu}_X) - \frac{1}{2}(\mathbf{y} - \mathbf{X})^T\Sigma_Y^{-1}(\mathbf{y} - \mathbf{X}) \\
&= -\frac{1}{2}\mathbf{X}^T\Sigma_X^{-1}\mathbf{X} + \boldsymbol{\mu}_X^T\Sigma_X^{-1}\mathbf{X} - \frac{1}{2}\mathbf{y}^T\Sigma_Y^{-1}\mathbf{y} + \mathbf{y}^T\Sigma_Y^{-1}\mathbf{X} - \frac{1}{2}\mathbf{X}^T\Sigma_Y^{-1}\mathbf{X} + \text{常数项} \\
&= -\frac{1}{2}\mathbf{X}^T(\Sigma_X^{-1} + \Sigma_Y^{-1})\mathbf{X} + (\boldsymbol{\mu}_X^T\Sigma_X^{-1} + \mathbf{y}^T\Sigma_Y^{-1})\mathbf{X} + \text{常数项}
\end{aligned}$$

**步骤3:配方法**

为了将上式配成 $-\frac{1}{2}(\mathbf{X} - \boldsymbol{\mu}_{X|Y})^T\Sigma_{X|Y}^{-1}(\mathbf{X} - \boldsymbol{\mu}_{X|Y})$ 的形式:

1. 确定 $\Sigma_{X|Y}^{-1}$:
   $$\Sigma_{X|Y}^{-1} = \Sigma_X^{-1} + \Sigma_Y^{-1}$$

2. 确定 $\boldsymbol{\mu}_{X|Y}$:
   完全平方项为:
   $$-\frac{1}{2}(\mathbf{X} - \boldsymbol{\mu}_{X|Y})^T\Sigma_{X|Y}^{-1}(\mathbf{X} - \boldsymbol{\mu}_{X|Y}) = -\frac{1}{2}\mathbf{X}^T\Sigma_{X|Y}^{-1}\mathbf{X} + \boldsymbol{\mu}_{X|Y}^T\Sigma_{X|Y}^{-1}\mathbf{X} + \text{常数项}$$

   对比系数，$\mathbf{X}$ 的一次项系数应该相等:
   $$\boldsymbol{\mu}_{X|Y}^T\Sigma_{X|Y}^{-1} = \boldsymbol{\mu}_X^T\Sigma_X^{-1} + \mathbf{y}^T\Sigma_Y^{-1}$$

   转置后:
   $$\Sigma_{X|Y}^{-1}\boldsymbol{\mu}_{X|Y} = \Sigma_X^{-1}\boldsymbol{\mu}_X + \Sigma_Y^{-1}\mathbf{y}$$

   因此:
   $$\boldsymbol{\mu}_{X|Y} = \Sigma_{X|Y}(\Sigma_X^{-1}\boldsymbol{\mu}_X + \Sigma_Y^{-1}\mathbf{y})$$

**步骤4:写出后验分布**

因此，后验分布为:
$$p(\mathbf{X}|\mathbf{Y}=\mathbf{y}) = \mathcal{N}(\boldsymbol{\mu}_{X|Y}, \Sigma_{X|Y})$$

其中:
$$\begin{aligned}
\Sigma_{X|Y}^{-1} &= \Sigma_X^{-1} + \Sigma_Y^{-1} \\
\boldsymbol{\mu}_{X|Y} &= \Sigma_{X|Y}(\Sigma_X^{-1}\boldsymbol{\mu}_X + \Sigma_Y^{-1}\mathbf{y})
\end{aligned}$$

这与一维情况的形式完全对应。

## 3. 总结

本文详细证明了正态分布的两个核心性质:**加法法则**和**乘法法则（共轭性）**。

### 3.1 加法法则

**核心结论**:两个独立正态分布的和仍然是正态分布。

- **一维情况**:若 $X_1 \sim \mathcal{N}(\mu_1, \sigma_1^2)$，$X_2 \sim \mathcal{N}(\mu_2, \sigma_2^2)$ 且独立，则
  $$X_1 + X_2 \sim \mathcal{N}(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$$

- **多维情况**:若 $\mathbf{X}_1 \sim \mathcal{N}(\boldsymbol{\mu}_1, \Sigma_1)$，$\mathbf{X}_2 \sim \mathcal{N}(\boldsymbol{\mu}_2, \Sigma_2)$ 且独立，则
  $$\mathbf{X}_1 + \mathbf{X}_2 \sim \mathcal{N}(\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2, \Sigma_1 + \Sigma_2)$$

### 3.2 乘法法则（共轭性）

**核心结论**:正态先验与正态似然的乘积（后验）仍然是正态分布。

- **一维情况**:若 $X \sim \mathcal{N}(\mu_X, \sigma_X^2)$，$Y|X \sim \mathcal{N}(X, \sigma_Y^2)$，则
  $$p(X|Y=y) = \mathcal{N}(\mu_{X|Y}, \sigma_{X|Y}^2)$$
  其中:
  $$\frac{1}{\sigma_{X|Y}^2} = \frac{1}{\sigma_X^2} + \frac{1}{\sigma_Y^2}, \quad \mu_{X|Y} = \sigma_{X|Y}^2 \left(\frac{\mu_X}{\sigma_X^2} + \frac{y}{\sigma_Y^2}\right)$$

- **多维情况**:若 $\mathbf{X} \sim \mathcal{N}(\boldsymbol{\mu}_X, \Sigma_X)$，$\mathbf{Y}|\mathbf{X} \sim \mathcal{N}(\mathbf{X}, \Sigma_Y)$，则
  $$p(\mathbf{X}|\mathbf{Y}=\mathbf{y}) = \mathcal{N}(\boldsymbol{\mu}_{X|Y}, \Sigma_{X|Y})$$
  其中:
  $$\Sigma_{X|Y}^{-1} = \Sigma_X^{-1} + \Sigma_Y^{-1}, \quad \boldsymbol{\mu}_{X|Y} = \Sigma_{X|Y}(\Sigma_X^{-1}\boldsymbol{\mu}_X + \Sigma_Y^{-1}\mathbf{y})$$

### 3.3 为什么选择正态分布？

这两个性质共同解释了为什么生成模型常使用正态分布作为先验:

1. **数学便利性**:加法法则和乘法法则保证了分布形式在运算过程中保持不变，避免了复杂的分布转换
2. **计算高效性**:共轭性使得贝叶斯推断有闭式解，不需要复杂的数值积分
3. **理论完备性**:这些性质使得我们可以进行精确的数学分析和推导

因此，正态分布不仅是数学上"自然"的选择，也是计算上"高效"的选择，这就是为什么它在生成模型中如此重要的根本原因。
