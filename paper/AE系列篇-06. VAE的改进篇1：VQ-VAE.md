# 深度学习AE篇06. VAE的改进篇1：VQ-VAE

标准 VAE 使用连续潜在变量，其分布为高斯形式，对离散的、多模态的数据结构表达有限。VQ-VAE（Vector Quantized Variational Autoencoder）通过向量量化将连续潜在变量离散化，在保持 VAE 表达能力的同时获得离散表示的优势，并为 VQ-VAE-2、DALL-E 等自回归生成模型奠定基础。本章将介绍 VQ-VAE 的动机、理论、损失设计与代码实现。

## 1. VQ-VAE 的动机

### 1.1 VAE 的局限性

标准 VAE 的潜在变量服从连续分布：

$$q_\phi(z|x) = \mathcal{N}(z | \mu_\phi(x), \Sigma_\phi(x))$$

主要问题包括：

1. **连续潜在空间的局限**：难以自然表示离散、多模态结构
2. **符号数据不匹配**：语言、类别等符号数据缺乏天然的连续表示
3. **信息瓶颈不显式**：连续表示的信息容量无界，不利于学习紧凑、有界的离散码

### 1.2 VQ-VAE 的改进目标

VQ-VAE 旨在：

- **离散潜在表示**：用 codebook 将编码器输出量化为离散索引，得到离散潜在变量
- **保留表达能力**：编码器-解码器仍为连续映射，量化仅在中间一步完成
- **可扩展生成**：离散码可交由自回归模型（如 PixelCNN、Transformer）建模，用于高质量生成

## 2. VQ-VAE 的理论基础

### 2.1 整体结构

数据流为：

$$x \xrightarrow{\text{编码器 } E_\phi} z_e \xrightarrow{\text{向量量化 } Q} z_q \xrightarrow{\text{解码器 } D_\theta} \hat{x}$$

**组件说明**：

- **编码器** $E_\phi$：$x \to z_e$，将输入映射到连续潜在空间 $\mathbb{R}^d$
- **Codebook** $\mathcal{E} = \{e_1, e_2, \ldots, e_K\}$：$K$ 个可学习的 $d$ 维向量
- **向量量化** $Q$：$z_e \to z_q$，将 $z_e$ 映射到最近的 codebook 向量
- **解码器** $D_\theta$：$z_q \to \hat{x}$，从量化向量重构输入

### 2.2 数学表示

**编码**：

$$z_e = E_\phi(x) \in \mathbb{R}^d$$

**量化（最近邻）**：

$$k = \arg\min_{j \in \{1,\ldots,K\}} \|z_e - e_j\|^2, \qquad z_q = e_k$$

**解码**：

$$\hat{x} = D_\theta(z_q)$$

距离采用欧氏距离的平方：$\|z_e - e_j\|^2 = (z_e - e_j)^T(z_e - e_j)$，实现时可利用展开形式或预计算 $e_j^T e_j$ 以加速。

### 2.3 损失函数

总损失由三部分组成：

$$\mathcal{L}_{total} = \mathcal{L}_{recon} + \mathcal{L}_{codebook} + \beta\,\mathcal{L}_{commitment}$$

**重构损失**：衡量解码器重构质量

$$\mathcal{L}_{recon} = \|x - D_\theta(z_q)\|^2 = \|x - \hat{x}\|^2$$

**Codebook 损失（Embedding 损失）**：把被选中的 codebook 向量 $e_k$ 拉向编码器输出 $z_e$（更新 codebook）

$$\mathcal{L}_{codebook} = \|z_e - \text{sg}(z_q)\|^2$$

其中 $\text{sg}(\cdot)$ 表示停止梯度。梯度只更新 $e_k$，不经过 $z_e$。

**Commitment 损失**：把编码器输出 $z_e$ 拉向量化结果 $z_q$，避免编码器输出在 codebook 之间剧烈抖动

$$\mathcal{L}_{commitment} = \|\text{sg}(z_q) - z_e\|^2$$

$\beta$ 为 commitment 权重，常用 0.25。

**梯度流向**：

- 解码器：只受 $\mathcal{L}_{recon}$ 影响
- 编码器：受 $\mathcal{L}_{recon}$（经直通）和 $\beta\,\mathcal{L}_{commitment}$ 影响
- Codebook：只受 $\mathcal{L}_{codebook}$ 影响

### 2.4 直通估计器（Straight-Through Estimator）

量化 $Q(z_e)=e_k$ 不可微（$\arg\min$ 为离散操作），无法直接对 $z_e$ 反传梯度。

**直通做法**：前向使用量化结果，反传时把损失对 $z_q$ 的梯度原样传给 $z_e$。

实现上可写为：

$$z_q^{ST} = z_q + (z_e - \text{sg}(z_e))$$

前向：$z_q^{ST}$ 的取值等于 $z_q$；反向：$\frac{\partial z_q^{ST}}{\partial z_e} = I$，因此 $\frac{\partial \mathcal{L}}{\partial z_e} = \frac{\partial \mathcal{L}}{\partial z_q^{ST}}$，解码器传来的梯度得以穿过量化层更新编码器。

### 2.5 训练与生成流程概要

**训练**：对每个样本 $x$，依次执行：编码得 $z_e$ → 最近邻得 $z_q$ → 直通得 $z_q^{ST}$ → 解码得 $\hat{x}$ → 计算 $\mathcal{L}_{recon}$、$\mathcal{L}_{codebook}$、$\mathcal{L}_{commitment}$ → 反向传播更新 $E_\phi$、$D_\theta$ 和 codebook $\mathcal{E}$。

**生成**：若仅用 VQ-VAE 本身，可从 codebook 均匀采样索引 $k \sim \text{Uniform}\{1,\ldots,K\}$，取 $z_q = e_k$，再解码得 $\hat{x} = D_\theta(z_q)$。实际应用中多在离散潜在空间上训练自回归模型（如 PixelCNN）建模 $p(z)$，再从中采样 $z$ 后解码生成。

## 3. VQ-VAE 的关键特性

### 3.1 离散潜在空间

- 潜在变量为离散索引或 one-hot 在 codebook 上的分布，适合符号、多模态结构
- 信息容量有界（最多 $K$ 个码），有利于学习有意义的压缩表示

### 3.2 无 KL 先验项

- 标准 VAE 用 KL$(q_\phi(z|x)\|p(z))$ 约束潜在空间
- VQ-VAE 用 codebook 损失 + commitment 损失替代，使 $z_e$ 与 $z_q$ 对齐，无需显式高斯先验

### 3.3 与自回归生成结合

- 离散码序列可视为“离散潜像”，用 PixelCNN、Transformer 等建模 $p(z_{1:L})$，再解码为图像或序列，形成 VQ-VAE-2、DALL-E 等两阶段生成框架

## 4. VQ-VAE 与标准 VAE 的对比

| 特性       | 标准 VAE                    | VQ-VAE                          |
|------------|-----------------------------|----------------------------------|
| 潜在变量   | 连续 $z \sim q_\phi(z|x)$   | 离散 $z = e_k$，$k = \arg\min_j \|z_e - e_j\|^2$ |
| 正则化     | KL 散度                     | Codebook 损失 + Commitment 损失  |
| 先验       | $p(z)=\mathcal{N}(0,I)$      | 训练时可视为均匀 over codebook；生成时常另训自回归先验 |
| 梯度传递   | 重参数化                    | 直通估计器穿过量化层             |

## 5. 代码实现

本节基于项目中的 `code/dl/ae/vq_vae/` 实现说明关键模块。

### 5.1 模型结构：VQVAE 类

编码器使用卷积下采样 + 残差块，codebook 用 `nn.Embedding`，解码器用转置卷积上采样：

```python
class VQVAE(nn.Module):
    """VQ-VAE 模型（CNN 架构）"""
    def __init__(self, input_dim, dim, n_embedding):
        super().__init__()
        # Encoder: 卷积下采样
        self.encoder = nn.Sequential(
            nn.Conv2d(input_dim, dim, 4, 2, 1),   # 28x28 -> 14x14
            nn.ReLU(),
            nn.Conv2d(dim, dim, 4, 2, 1),        # 14x14 -> 7x7
            nn.ReLU(),
            nn.Conv2d(dim, dim, 3, 1, 1),
            ResidualBlock(dim),
            ResidualBlock(dim)
        )
        # Codebook：可学习的嵌入表
        self.vq_embedding = nn.Embedding(n_embedding, dim)
        self.vq_embedding.weight.data.uniform_(-1.0 / n_embedding, 1.0 / n_embedding)

        # Decoder: 转置卷积上采样
        self.decoder = nn.Sequential(
            nn.Conv2d(dim, dim, 3, 1, 1),
            ResidualBlock(dim),
            ResidualBlock(dim),
            nn.ConvTranspose2d(dim, dim, 4, 2, 1),   # 7x7 -> 14x14
            nn.ReLU(),
            nn.ConvTranspose2d(dim, input_dim, 4, 2, 1)  # 14x14 -> 28x28
        )
        self.n_downsample = 2
```

### 5.2 前向传播：量化与直通

在 `forward` 中完成编码、最近邻量化与直通，再解码：

```python
def forward(self, x):
    # 编码: x -> z_e
    ze = self.encoder(x)  # (N, C, H, W)

    # 向量量化：最近邻查找
    embedding = self.vq_embedding.weight.data   # (K, C)
    N, C, H, W = ze.shape
    K, _ = embedding.shape
    embedding_broadcast = embedding.reshape(1, K, C, 1, 1)
    ze_broadcast = ze.reshape(N, 1, C, H, W)
    distance = torch.sum((embedding_broadcast - ze_broadcast) ** 2, 2)
    nearest_neighbor = torch.argmin(distance, 1)  # (N, H, W)

    # zq: (N, C, H, W)
    zq = self.vq_embedding(nearest_neighbor).permute(0, 3, 1, 2)

    # 直通估计器：前向用 zq，反向梯度传给 ze
    decoder_input = ze + (zq - ze).detach()

    x_hat = self.decoder(decoder_input)
    return x_hat, ze, zq
```

对应公式：$z_q^{ST} = z_e + (z_q - \text{sg}(z_e))$，解码器输入为 `decoder_input`。

### 5.3 损失函数

与理论一致：重构用 MSE；codebook 损失用 `ze.detach()` 与 `zq` 的 MSE（只更新 codebook）；commitment 用 `ze` 与 `zq.detach()` 的 MSE（只更新编码器）。

```python
def loss_function(x_hat, x, ze, zq, embedding_loss_weight=1.0, commitment_loss_weight=0.25):
    recon_loss = F.mse_loss(x_hat, x)
    # 将 codebook 向量拉向 ze
    embedding_loss = F.mse_loss(ze.detach(), zq)
    # 将 ze 拉向 codebook 向量
    commit_loss = F.mse_loss(ze, zq.detach())
    total_loss = recon_loss + embedding_loss_weight * embedding_loss + commitment_loss_weight * commit_loss
    return total_loss, recon_loss, embedding_loss, commit_loss
```

### 5.4 编码与解码接口（推理）

推理时只需离散索引，因此 `encode` 只返回最近邻索引；`decode` 根据索引取 codebook 向量再解码：

```python
@torch.no_grad()
def encode(self, x):
    """编码为 codebook 索引 (N, H, W)，供自回归模型等使用"""
    ze = self.encoder(x)
    # 与 forward 中相同的最近邻查找
    embedding = self.vq_embedding.weight.data
    N, C, H, W = ze.shape
    K, _ = embedding.shape
    embedding_broadcast = embedding.reshape(1, K, C, 1, 1)
    ze_broadcast = ze.reshape(N, 1, C, H, W)
    distance = torch.sum((embedding_broadcast - ze_broadcast) ** 2, 2)
    nearest_neighbor = torch.argmin(distance, 1)
    return nearest_neighbor

@torch.no_grad()
def decode(self, discrete_latent):
    """从索引 (N, H, W) 解码为图像"""
    zq = self.vq_embedding(discrete_latent).permute(0, 3, 1, 2)
    return self.decoder(zq)
```

### 5.5 训练循环与配置

训练时对每个 batch 计算 `x_hat, ze, zq = model(x)`，再调用 `loss_function` 并反传；配置中可设置 `embedding_loss_weight=1.0`、`commitment_loss_weight=0.25`（对应 $\beta$）。核心片段如下：

```python
for x, label in train_loader:
    x = x.to(device)
    x_hat, ze, zq = model(x)
    loss, recon_loss, embedding_loss, commit_loss = loss_function(
        x_hat, x, ze, zq, embedding_loss_weight, commitment_loss_weight)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

配置文件（如 `config.yaml`）示例：`input_dim=1`（MNIST），`dim=64`，`n_embedding=32`，`commitment_loss_weight=0.25`。

### 5.6 推理：重构与从 codebook 生成

- **重构**：直接 `x_hat, ze, zq = model(x)`，用 `x_hat` 与原始 `x` 对比可视化。
- **从 codebook 生成**：用 `indices = model.encode(x_train)` 得到训练集上的离散码，再 `generated = model.decode(indices)` 展示解码效果；若要真正“从先验生成”，需在离散空间上训练 PixelCNN 等再采样（见项目中 `train_pixelcnn.py`、`gen_with_pixelcnn.py`）。

## 6. VQ-VAE 的优势与应用

### 6.1 优势

- **离散表示**：更贴合符号、语言、多模态数据，便于与自回归模型结合
- **有界容量**：codebook 大小 $K$ 显式控制表示容量，有利于学习紧凑语义
- **即插即用**：可与现有 VAE 类编码器-解码器架构结合，仅增加量化层与两项 VQ 损失

### 6.2 应用场景

- **图像压缩与重构**：低维离散码 + 解码器实现有损压缩与重建
- **两阶段生成**：VQ-VAE 学习离散潜像，PixelCNN/Transformer 建模潜像分布（VQ-VAE-2、DALL-E）
- **语音与视频**：离散码便于与序列模型结合，用于语音表示、视频帧的离散潜空间建模

## 7. 总结

VQ-VAE 通过向量量化将 VAE 的连续潜在变量离散化，在保持编码-解码表达能力的同时获得离散表示的优势。要点包括：

1. **架构**：编码器 → 最近邻量化（codebook）→ 直通 → 解码器；损失为重构 + codebook + commitment。
2. **直通估计器**：解决量化不可微问题，使梯度穿过量化层更新编码器。
3. **双损失**：codebook 损失更新 codebook，commitment 损失约束编码器输出靠近 codebook，无需 KL 先验。

结合项目中的 `vq_vae/vq_vae.py`、`train_infer.py` 与配置文件即可复现训练与重构；若要完整生成流程，需在离散潜在空间上再训练自回归先验（如 PixelCNN）。
